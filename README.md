🏎️ F1 Driver Performance Review
Sistema Back-end para gerenciamento e análise de desempenho de pilotos da Fórmula 1.

📌 Sobre o projeto
O F1 Driver Performance Review é um projeto desenvolvido com o objetivo de aplicar conhecimentos em Java e desenvolvimento Back-end, utilizando dados relacionados ao automobilismo.

Tecnologias utilizadas
Java 25
Spring Boot
Spring Data JPA
PostgreSQL
Maven
Hibernate
Funcionalidades planejadas
Analises, comparações, estatisticas.

Status do projeto
Em desenvolvimento.

Desenvolvido como projeto de estudo e evolução em Java Back-end.
